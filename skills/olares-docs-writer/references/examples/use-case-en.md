# Achieve goal with AppName

AppName is a tool that helps you do something useful. This guide shows you how to install and configure it on Olares.

## Learning objectives

By the end of this tutorial, you will learn how to:
- Install AppName from the Market.
- Configure basic settings.
- Complete your first task.

## Prerequisites

Before you begin, make sure:
- Olares is installed and running.
- You have administrator access.

## Install AppName

1. Open the **Market** app in your Olares web interface.
2. Search for "AppName".
3. Click **Get**, then click **Install**.
   ![AppName in Market](../public/images/manual/use-cases/appname-market.png#bordered)
4. Wait for the installation to complete.

## Configure AppName

### Set up the connection

1. Open **AppName** from the Launchpad.
2. Go to **Settings** > **Connections**.

   :::tip Finding your API key
   You can find your API key in the Account section of the provider's website.
   :::

3. Enter your API key and click **Save**.

## Use AppName

Now that AppName is configured, you can start using it:

1. Click **New Project**.
2. Enter your parameters.
3. Click **Generate** to create your output.

## FAQ

### Why do I see an error when connecting?

If you encounter connection errors:
1. Check your network connection.
2. Verify your API key is correct.
3. Ensure the service is running.
