# 使用 AppName 实现目标

AppName 是一款帮助你完成有用工作的工具。本指南介绍如何在 Olares 上安装和配置它。

## 学习目标

完成本教程后，你将学会：
- 从应用市场安装 AppName
- 配置基本设置
- 完成第一个任务

## 前置条件

开始之前，请确保：
- Olares 已安装并运行
- 你拥有管理员权限

## 安装 AppName

1. 在 Olares 网页界面中打开**应用市场**。
2. 搜索 "AppName"。
3. 点击**获取**，然后点击**安装**。
   ![AppName 应用市场](/images/manual/use-cases/appname-market.png)
4. 等待安装完成。

## 配置 AppName

### 设置连接

1. 从启动台打开 **AppName**。
2. 进入**设置** > **连接**。

   :::tip 查找 API 密钥
   你可以在服务商网站的账户页面找到 API 密钥。
   :::

3. 输入 API 密钥并点击**保存**。

## 使用 AppName

配置完成后，你可以开始使用：

1. 点击**新建项目**。
2. 输入参数。
3. 点击**生成**创建输出。

## 常见问题

### 连接时为什么会出现错误？

如果遇到连接错误：
1. 检查网络连接。
2. 确认 API 密钥正确。
3. 确保服务正在运行。
